# OxyLens

See how your company uses AI.

OxyLens is an AI Operations Dashboard that provides visibility into AI adoption, usage, spend, and productivity across organizations.

Built to help teams understand how AI is being used, which models drive the most value, and where optimization opportunities exist.

## Features

* AI Usage Analytics Dashboard
* Model Usage Breakdown
* Team Adoption Tracking
* AI Spend Monitoring
* Productivity Insights
* AI Activity Feed
* Governance & Risk Overview
* Modern Enterprise UI

## Dashboard Modules

### AI Usage Analytics

Track AI requests and adoption trends across the organization.

### Model Insights

Monitor usage distribution across:

* GPT-4o
* Claude
* Gemini
* Open Source Models

### Team Adoption

Compare AI utilization across:

* Engineering
* Sales
* Marketing
* Operations

### Activity Feed

View recent AI-powered actions and workflows across teams.

### AI Spend Monitoring

Understand spending patterns and identify optimization opportunities.

### Governance & Risk

Monitor compliance, security posture, and AI tool usage.

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Recharts

## Getting Started

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
